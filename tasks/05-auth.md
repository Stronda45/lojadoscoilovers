# 05 — Auth (cadastro/login)

Estimativa: 4h · Bloqueada por: 04

## Objetivo
Cliente final consegue criar conta e logar. Sem tela bonita — funcional.

## Tarefas
- [ ] Endpoint de cadastro (cria `User` + `Customer`).
- [ ] Endpoint de login (token DRF ou sessão — o mais simples de integrar com o
      frontend).
- [ ] Validação básica (e-mail único, senha mínima).

## Aceite
- [ ] Cadastro cria conta real no banco.
- [ ] Login devolve um token/sessão válido usável nas próximas requests.
