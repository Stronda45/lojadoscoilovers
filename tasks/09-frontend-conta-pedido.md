# 09 — Frontend: login/cadastro/pedido (sem design)

Estimativa: 5h · Bloqueada por: 05, 06

## Objetivo
Cliente final consegue criar conta, logar e confirmar um pedido, tudo sem estilo.

## Tarefas
- [ ] Tela de cadastro (nome, e-mail, senha, endereço, telefone).
- [ ] Tela de login.
- [ ] Botão "Pedir" no resultado da busca (task 08) → confirma pedido.
- [ ] Aviso visível: "disponibilidade sujeita a confirmação" antes/depois de pedir.
- [ ] Lista simples dos próprios pedidos.

## Aceite
- [ ] Fluxo completo funciona: cadastra → loga → busca → pede → aparece na lista de
      pedidos.
